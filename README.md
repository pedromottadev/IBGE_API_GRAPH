| ## 📘 Descrição  <br> O **IBGE API PROJECT** é uma aplicação web que utiliza a **API pública do IBGE** para consultar a frequência de nomes no Brasil ao longo das décadas. Os dados são tratados e exibidos em um **dashboard interativo** desenvolvido com **Streamlit** e **Pandas**.  | ## 📘 Description  <br> The **IBGE API PROJECT** is a web application that uses the **IBGE public API** to query the frequency of names in Brazil over the decades. The data is processed and displayed in an **interactive dashboard** built with **Streamlit** and **Pandas**. |
